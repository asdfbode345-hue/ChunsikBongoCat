춘식이 봉고캣 v1.0 (윈도우용 프로토타입)

[실행]
1. Windows 10/11에 Python 3.11~3.13 설치 (설치 시 Add Python to PATH 선택 권장)
2. 실행하기.bat 더블클릭 (첫 실행 때 라이브러리 설치, 인터넷 필요)
3. 작업표시줄 오른쪽 트레이 아이콘을 우클릭해 설정

[EXE 만들기]
EXE_만들기.bat 실행 -> dist/ChunsikBongoCat/ChunsikBongoCat.exe
EXE 파일만 옮기지 말고 해당 폴더 전체를 함께 옮겨야 합니다.
Windows에서 빌드해야 Windows EXE가 만들어집니다.

[조작]
- 춘식이 위에서 마우스 왼쪽 버튼 드래그: 위치 이동
- 춘식이 우클릭 또는 트레이 아이콘 우클릭: 설정
- 트레이 아이콘 클릭: 춘식이 보이기/숨기기
- 크기: 280/400/560px
- 항상 위에 표시: 체크 ON/OFF
- 키보드 입력: 작은 바운스 및 키보드 빛 효과
- 마우스 클릭: 핑크 클릭 링
- 마우스 이동: 마우스 주변 반응

[현재 버전 한계]
춘식이 앞발을 독립적으로 움직이는 정교한 애니메이션이 아닌, 전체 이미지의 바운스 및 입력 강조 효과입니다.
실제 Windows 환경에서 실행 테스트는 수행하지 못했습니다.
키보드/마우스 입력은 로컬에서 반응 처리에만 사용하며 파일 저장 또는 전송하지 않습니다.
일부 관리자 권한 게임/보안 프로그램에서는 전역 입력 감지가 제한될 수 있습니다.
